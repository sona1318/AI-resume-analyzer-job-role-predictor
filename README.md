# AI Resume Analyzer & Job Fit Predictor 🚀

A powerful AI tool designed to analyze resumes and predict job roles based on skill categories.

### 🔗 [Live Demo - Visit the Website](https://ai-job-fit-analyzer.streamlit.app/)

## Features
*   **Resume Parsing:** Upload PDF resumes for instant analysis.
*   **Job Role Prediction:** Uses Machine Learning to suggest the best-fit role.
*   **Skill Categorization:** Visualizes tech skills and categories.

## Built With
*   **Python** & **Streamlit**
*   **Machine Learning Models** (scikit-learn)
*   **Data Visualization** (Matplotlib)
